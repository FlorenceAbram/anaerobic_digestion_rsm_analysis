# Provenance And Scope

The files in `data/input/` are supplied study data used for an independent
statistical reanalysis. They are retained as analysis inputs and are not
presented as newly collected observations.

This repository is a derivative analysis package. It contains no claim about
data ownership, author order or contribution history. Before any public
release, the corresponding author or data custodian must confirm that
redistribution of the included data is permitted and must add the appropriate
data-use statement and licence.

The repository deliberately contains only the analysis code and the
machine-readable inputs required to reproduce the reanalysis. Derived outputs
are regenerated by running the code and are not tracked. Manuscript drafts,
correspondence, extraction logs and legacy project artefacts are outside the
scope of this package.

The four response models use the supplied 180-observation design table.
Microbial responses follow the audited transformation
`pmax(log10(count + 1), 1)`; methane is untransformed. Recipe labels and all
modelling decisions are documented in the analysis scripts.
