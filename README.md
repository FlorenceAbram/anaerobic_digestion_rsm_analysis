# Anaerobic Digestion RSM Analysis

Code and input data for the independent statistical reanalysis of the four
response-surface models used in the manuscript of AD-Farm modelling 

The four responses are coliforms, *E. coli*, enterococci and methane. The
primary analysis is a transparent full-quadratic response-surface model fitted
with base R `lm()` using explicit recipe contrasts. The models were written and
fitted independently for this reanalysis; no earlier code, coefficients, or
analytical implementation was reused.

## Contents

This repository holds **only the analysis code and the input data**. Every
table, figure, diagnostic plot and fitted model object is regenerated by
running the code, so no derived output is tracked here.

```
data/input/     input data used by the analysis
R/              R analysis and plotting scripts
python/         Table 3 hard-constraint optimisation
tests/          reconstruction checks
run_analysis.R  single entry point for the R pipeline
```

### `data/input/`

| File | Description |
|---|---|
| `trial_data.csv` | Raw trial measurements: 180 observations, untransformed microbial counts and methane |
| `analysis_design.csv` | Design table with transformed responses as modelled |
| `combined_data.csv` | Trial data joined to day-0 initial counts |
| `day0.csv` | Day-0 initial microbial counts (supporting data) |

### `R/`

| Script | Purpose |
|---|---|
| `01_reconstruct_rsm_models.R` | Builds the design, applies response transformations, fits the four full-quadratic models |
| `02_anova_lack_of_fit.R` | ANOVA term tests, lack-of-fit and pure-error partition |
| `03_model_diagnostics.R` | Residual, leverage, Cook's distance and QQ diagnostics, with plots |
| `04_coliform_and_design_space.R` | Coliform consistency checks and design-space / convex-hull verification |
| `05_validation_uncertainty_importance.R` | Grouped cross-validation, bootstrap prediction uncertainty, factor importance, design sensitivity |
| `06_pca_exploratory.R` | Optional exploratory PCA, plus plots |

### `python/`

`corrected_rsm_table3_hard_constraints.py` reproduces the corrected Table 3.
It applies the recipe mapping (`FWS31` = 1S:3FW, `FWS12` = 2S:1FW,
`FWS13` = 3S:1FW), requires all three faecal indicator bacteria to satisfy the
selected threshold **simultaneously**, and restricts candidate settings to the
Box–Behnken convex design hull.

## Reproduce

R pipeline, from the repository root:

```r
source("run_analysis.R")
```

Requires base R only. The scripts write models, tables, figures and
diagnostics into `models/` and `outputs/`.

Table 3 optimisation:

```
python python/corrected_rsm_table3_hard_constraints.py
```

Requires `numpy`, `pandas`, `scipy` and `statsmodels`. Output is written to
`outputs/tables/corrected_table3.csv`.

The exploratory PCA is separate from the RSM reconstruction and validation and
is not used to support the primary model or the optimisation conclusions.

## Scope and limitations

Validation is internal and grouped by complete experimental condition. No
independent experiment, plant-scale trial or external laboratory dataset is
included. Significant lack of fit was retained and reported; the model was not
replaced solely to improve fit statistics. Predictions outside the
recipe-specific design hull are treated as extrapolations.

Optimisation must satisfy all three faecal indicator bacteria criteria at once.
Enterococci is the limiting parameter.

See `PROVENANCE.md` for the data-provenance and scope statement.
